# SkillLoop AI

**Don't just use AI. Learn with it. Build with it.**

SkillLoop AI is an adaptive learning platform that transforms AI from an "answer machine" into a true learning engine. Built for the Smart Education hackathon.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Hackathon Demo Flow
The application is pre-seeded with a **Demo Mode** for the hackathon presentation.
1. Click **Start Demo** from the landing page.
2. View the **Student Dashboard** showing 32% mastery in Recursion.
3. Open the **AI Tutor** for a Socratic-style chat interaction.
4. Complete the **Adaptive Assessment** to "level up" the Recursion mastery to 76%.
5. Visit the **Project Builder** to see the newly unlocked *Maze Solver using Recursion* project.
6. Switch to the **Teacher View** to see aggregate classroom analytics based on the updated mastery scores.
